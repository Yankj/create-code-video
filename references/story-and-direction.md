# 叙事与分镜导演

## 一句话 Topic

先写“观众看完会改变什么判断”。将主题名词与论点分开：主题可以是三款 Agent，论点是“竞争开始围绕普通人能否放心托付”。维度是论据，不必各占一页。

技术解释通常适合：冲突/误解 → 比较对象 → 机制如何工作 → 证据与限制 → 结论。宣传片可以是：悬念 → 形态揭示 → 能力展开 → 价值落点。按内容选择，不能把所有视频套成相同的五段式。

若十四页显得散，先检查重复结论、论据层级、概念跳转和缺失的因果桥。按语义合并镜头，而不是机械压缩成七页或加快全部旁白。

## 导演规格

每镜记录：

| 项目 | 决策 |
| --- | --- |
| 目的 | 此镜让观众理解哪一件事，为什么放在这里 |
| Hero | 唯一主要信息载体；名字、角色、状态变化 |
| Support | 解释因果/对照，何时出现，如何让位 |
| Texture | 背景运动是否有必要，幅度/透明度 |
| 主事件 | 从哪种状态到哪种状态，为何改变 |
| 相机 | 景别、位置、目标、运动缘由、落定时刻 |
| 转场 | 承接什么对象/形状/动作/空间 |
| 声音 | 旁白语义、重音、节拍、气口、SFX 动机 |
| 留白 | 主信息稳定后，观众实际可读多久 |
| 验收 | 画面能证明什么，如何检查 |

“看起来酷”不是可验收的镜头目的。机制动画的验收可以是：不看旁白也能辨认输入、动作、结果，以及失败后的改变。

## 把方向变成数值

以下是起点，按题材和实际音频调整。不要要求所有动作必须同长或必须整除某个单位。

```json
{
  "motion": {
    "tone": ["清晰", "有力", "亲近"],
    "enterSeconds": 0.42,
    "repositionSeconds": 0.65,
    "staggerSeconds": 0.08,
    "travelFractionOfWidth": 0.06,
    "overshoot": 0.02,
    "minimumReadHoldSeconds": 0.9,
    "primaryTransition": "persistent-object",
    "accentTransition": "occlusion-reveal"
  }
}
```

入场可用减速曲线，离场可用加速曲线，位置调整用平滑进出。恒速适合循环/匀速过程。量化数据到达真实值后稳定，避免弹跳超越数值暗示不存在的结果。

按重要性分配幅度、速度和亮度。背景持续运动并不自动让内容生动；也可能夺走注意力。做一次“删动效”检查：删除后理解不变的装饰，降低强度或移除。

## 镜头空间与节奏

- 全景交代结构，中景解释关系，特写只用于关键动作或证据；特写后给观众恢复上下文的机会。
- 相机由“发现 → 执行 → 结果”驱动。点击或路径变化发生后，镜头沿因果链抵达结果；不能每个段落都无理由绕一圈。
- 拆分对象、换位置、移动相机不要同时达到最大速度。快速动作后安排落定，重要术语出现后安排阅读。
- 画一条能量曲线：开头建立冲突，机制段起伏，关键揭示达到峰值，结论回落。峰值数量按内容控制，不强制每片只能一次。
- 总时长由信息密度和可读性决定；“更短”应先减少重复信息，而不是把所有动画、语音按相同比例压快。

## 持续对象示例

用同一份委托单讲 Agent：提出目标 → 分解步骤 → 执行返回结果 → 出错显示差异 → 修改计划 → 有证据地勾选完成。对象身份稳定，结构可以改变。

同一份单据跨镜时要保持坐标、尺度或可识别轮廓至少一项。不能前一帧在右侧消失，后一帧在左侧重建，却称作无缝转场。

更多实现见 [转场](transitions.md) 与 [Motion Lab](../examples/remotion-motion-lab/README.md)。结构检查见 [storyboard 样例](../examples/storyboard.example.json)。脚本检查结构和时间，不评价观点是否成立。
