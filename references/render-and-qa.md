# 渲染与验收

## 最小验证闭环

代表帧 → 最难镜头 1–3 秒片段 → 切点前后 → 全片输出。先确认真实 WebGL、字体与资源可捕获，再完善所有镜头。记录限制，不能把静帧图称作已完成视频。

确定性条件包括：同一输入、锁定依赖、固定种子、绝对时间、资源就绪、相同渲染环境。Shader 和 GPU 跨设备可能有细小差异；同机重复同帧应先通过。

乱序取帧（例如 90、0、179、90）检查是否出现历史污染。使用独立 browser render 验证无挂载前史，再在 Studio/Player 中来回 seek 检查持续实例。例子的数学测试不能代替 GPU 成片检查。

## 真正的播放检查

播放器显示 `playing=true`、播放图标、CSS 动画或前后截图，不证明时间在推进。确认两次状态的 currentFrame/currentTime 变大，或实际连续播放已渲染片段。

工具/播放器卡住时设置有界重试与单次超时，例如 15–30 秒检查一次，至多两次；随后使用另一可用播放器或渲染短片段检查。不要持续等待一个原生应用 API 到整轮挂起。替代检查做不到听感时如实记录。

## 时间与画面

使用半开帧区间 `[startFrame, endFrame)`。每个边界检查 `cut-1, cut, cut+1`，跨转场另查峰值帧。检查：

- 字体已加载、正文高对比、标题与字幕无冲突、手机缩放可读；
- 主对象/连线不被字幕挡住，场景边界没有提前露出下一镜；
- 相机无穿模/近裁剪，灯光不是平面黑剪影，粒子具有实际深度；
- 主事件完成后有读取时间，结论尾部无提前退场；
- 开头/结尾/稠密镜头/每种转场至少各一帧，联系表抽样不能证明所有帧通过。

## 文件验证

```bash
python scripts/validate_storyboard.py examples/storyboard.example.json
python scripts/qa_video.py output.mp4 --width 1080 --height 1920 --fps 30 --duration 18 --out qa.json
python scripts/inspect_video.py output.mp4 --out frames --times 0,3,6,9,12,15,17.8
```

`qa_video.py` 使用 ffprobe、完整 ffmpeg 解码，并可测音频响度；尺寸/时长预期值可省略。完整解码发现编码/读取错误，不证明设计、所有黑帧或听感。黑色本来就可能是合法转场，不能用无黑帧检测冒充画面质量。

`inspect_video.py` 额外需要 Pillow，只写新/空输出目录。打开联系表检查真实画面。连贯性检查仍需短片段或播放。

## 声音

核对采样率、声道、音轨与字幕，测量只是辅助。连续听看段落连接和结尾：错读、声音身份漂移、响度跳变、截尾、音乐抢话。ASR 匹配只支持文本核对，不能替代试听。

如果当前环境不能听声音，保留这个具体限制；可以使用用户试听反馈，不能写成自己已听。不要用有音轨来证明“音效已优化”。

## 复现与交付

交付源码包含：依赖锁、项目配置、素材清单、入口、运行命令、最终时长、必要环境。可选 TTS/模型/品牌素材单独说明获取方式，不把私人凭据、私有截图、无许可音频或大模型缓存打包。

交付完成后简洁列实际文件链接和做过的验证。示例中没有声音就明确无声示例；不承诺它自动生成正式配音。
