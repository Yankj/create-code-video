# 转场与连续性

转场回答“为什么从这里到那里”。先选择关系，再选择效果。可以固定主家族并留少量强调变化，但无需每镜一种新花样。

| 关系 | 表达 | 关键连续性 | 风险 |
| --- | --- | --- | --- |
| 同一个任务进入新阶段 | 持续对象移动/展开 | ID、尺度/轮廓、位置或路径 | 卸载后重建造成跳变 |
| 由整体进入细节 | 相机推进/空间旅行 | 目标与上下文、景深与景别 | 一直运动导致读不清 |
| 不同对象有同一结构 | 形状/动作匹配切 | 切点轮廓、运动方向和速度 | 只淡入淡出，缺失匹配 |
| 跨章节切换 | 遮挡揭示/清楚硬切 | 遮挡时交换内容，方向明确 | 全屏遮挡太久，误作黑帧 |
| 失败与修正 | 局部路径/状态重写 | 哪一步失败，下一次哪里不同 | RGB 故障长期覆盖正文 |
| 情绪放缓与收束 | 安静落定/简洁淡变 | 音尾、结论、停留 | 结尾突然加速或新爆炸特效 |

## 实现协议

### 持续对象

对象放在镜头序列外的共享层，用**全局帧**控制位置、结构和状态；局部内容可以更换。转场期间仍是同一个可追踪对象。见 [Motion Lab](../examples/remotion-motion-lab/README.md)。

若不能保持同一个实例，也能通过匹配切实现连续感：让切点前后位置、尺度、轮廓、方向对齐。记录误差而不是只说“无缝”。

### 遮挡揭示

先让遮挡进入并覆盖切换区域，再交换内容，最后离开。按目标帧率检查切点前一帧、切点、后一帧，避免边缘泄露下一镜。示例用 SVG 路径和帧函数，所有几何可定位。

### 相机旅行

将前后对象放在同一世界中：建立 → 接近动作 → 动作触发 → 沿路径抵达结果 → 落定。位置、look-at 和视场角分别控制，避免相机穿过主体或 near plane 剪切。主体位移与相机位移需要区分；后者会同时改变整个世界的视差和遮挡。

需要真实三维就移动 PerspectiveCamera；二维 UI 放大可以是 SVG/DOM 虚拟相机，不声称产生真实三维视差。

### 时间账本

普通半开镜头区间 `[start, end)` 可无重叠。交叉转场则明确重叠时长与有效总长。

Remotion `TransitionSeries.Transition` 会缩短总长：`sum(scene durations) - sum(transition durations)`。Overlay 覆盖切点而不缩短总长；用当前包 API 检查可相邻条件。持续对象应在 TransitionSeries 外层使用全局时间。

HyperFrames 用有限可 seek 时间轴与明确时长；GSAP 只有一个渲染主时钟。3D 与 DOM 同步收到 seek 事件，不能一个按墙钟跑、一个按时间轴跑。

Shader 合成需要两幅场景纹理、资源就绪、正确尺寸/色彩空间。若使用 HyperFrames 的 DOM→纹理捕获，要核对其当前 html2canvas 限制；这些限制不能泛化为所有 CSS/Remotion 禁止规则。

## 节奏起点

技术解释可从约 0.35–0.65 秒的位置/章节转场试起，强调切可以短，收束可以慢。最终依赖语义、阅读和音轨，不把这些范围当成硬阈值。

转场中限制需要逐字阅读的内容；落定后再出现新术语。视觉动量与音乐不必每次完全同拍，但关键落点要有意设计。删掉无必要的转场音效往往比加音效更有效。
