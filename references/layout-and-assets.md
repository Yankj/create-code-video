# 版式、字幕与图形资产

## 手机画布

安全区是可配置的投放参数。根据平台 UI、实际发布方式和画布比例确定顶部、右侧操作栏与底部文字遮挡。不要把某次 1080×1920 的像素值直接搬到其他尺寸。

先建立标题、机制主体、字幕、来源四个层级。字幕区预留高度，主物体和连线不能依靠字幕出现前的空位。来源小字可以辅助核验，但不能承载必须读懂的反证或关键定义。

代表帧缩到约 360px 宽检查：是否两秒内能找到主信息，中文有没有孤字/不自然断行，多行标题是否压缩主体，右侧 UI 是否挡字。字号通过这个检查决定，不追求统一的“万能字号”。

## 把布局写成可检查的约束

1. 用同一设计坐标系配置标题、机制主体、字幕与页脚。相同比例可以整体缩放；换比例要重新排版。主对象的位置由字幕保留区与最小间距反推，不能另写一个互不关联的固定 top。
2. 卡片明确宽高、内边距和文字行高，图标固定尺寸且不参与 flex 缩小。用对齐容器统一图标与文字基线；字体回退不能决定卡片是否撞上字幕。
3. 动画检查**变换后的**边界。给缩放指定原点，间距还要容纳阴影/描边的视觉扩张。三维视口与文字区分开；相机改变 aspect 后要重新取景。
4. 字体/资源就绪后，用真实浏览器测量 DOM bounding rect、文本 Range 与 scroll bounds，统一换算到设计坐标。检查文字是否超出槽位、内容是否留在卡片内、受保护区域是否有足够间距。不能只比较写在配置里的两个数字。
5. 明确哪些层允许重叠，例如遮挡转场、背景纹理、验收对象与机制主体。自动检查只约束需要保护的关系，不做“任何对象都不得相交”的规则。
6. 默认超限报出对象、帧和测量值并停止导出。先改写/断行，再调整版式；不能用 overflow:hidden 或无限缩小字体掩盖问题。用故意重叠、超长文字反例验证检查确实失败。
7. 覆盖首尾、最长文案、动作极值、切点前后、转场峰值；约束可在每个导出帧执行。仍需查看手机尺寸画面，自动检查不评价艺术层级。

可复用 [布局配置](../examples/remotion-motion-lab/src/layout.mjs)、[DOM 测量与规则](../examples/remotion-motion-lab/src/layout-contract.mjs) 和 [帧检查](../examples/remotion-motion-lab/scripts/render-check.mjs)。本例 72 设计像素的卡片/字幕间距只用于其 9:16 画布；平台安全区另行配置。

## 更亮眼的字幕

- 稳定浅色正文 + 深色底板/描边；强调词可用明黄、青绿或品牌强调色，先检查实际背景对比。
- 每条突出少量有意义的词，不逐字变彩虹。颜色与类别保持一致，例如事实、机制和判断不能无规则换色。
- 文案按语义断句，常用一到两行；过长先改写或分段。字幕时间基于实际语音，并在重音处适度同步强调。
- 旁白已经解释的词可以出现在字幕，机制主体显示关系/状态；避免同一句话在标题、卡片、字幕重复三遍。
- 即使静音，观众仍应看懂核心问题、比较关系与结论。字幕不是唯一的信息通道。

## Logo / 界面 / 吉祥物

把素材当作身份与证据，不是填空装饰。

1. 首次出现用产品名与正确图形一起建立识别。产品 Logo、母公司 Logo、应用图标不是同一个对象。
2. 优先官方品牌页、官方产品页面和可核验截图。记录 URL、获取日期、权利/使用条件、裁剪与修改；不把搜索结果缩略图当作授权证明。
3. 界面截图只展示对应论点需要的区域，放大真实操作入口与结果；示意 UI 明确标为“示意”，不能伪造实际产品行为。
4. 吉祥物有官方身份才按官方身份介绍。用户自建角色或产品演示中的个人角色，不能当作产品统一吉祥物。
5. 让图形参与叙事：Logo 标识对比对象，界面解释门槛/授权，角色连接委托与结果。只在角落贴三个图标没有增加机制解释力。
6. 占位图形用自绘几何形与文字标签，不能画一个近似官方标志后声称已找到真 Logo。

项目用 [资产清单](../examples/asset-manifest.example.json) 记录来源与改动。示例不分发第三方 Logo、私有截图、模型权重或声音样本。

## 封面单独设计

封面是缩略图命题，不必复制正片背景。可以采用大胆对比、放大身份图形、紧凑标题和单一冲突词。保留准确性，例如“为什么没同样破圈”不能改成“技术彻底落后”。

在原尺寸和缩略图分别检查文字、焦点和边缘裁切。避免小字解释十个维度。封面与视频各自保存，便于平台发布。
