# 儿童科普（纯代码）题材

这是 `create-code-video` 的题材插件，不是平行 Skill。制作流程、TTS 选型、版式、渲染验收仍走主 [SKILL.md](../SKILL.md)。本篇只补 3–8 岁口语科普的信息结构、动效禁忌、科学口径和轻验收。

可运行样例：[彩虹短片](../examples/science-rainbow/README.md)。

## 何时读取

用户要「给小朋友讲科学」「纯代码儿童科普」「彩虹/水滴/光的色散」这类片子时读本篇。不要另开一个 Skill，也不要把本篇升格成主入口。

视觉默认仍由代码绘制或编排，不调用视频或图像生成模型。角色、实拍、生成镜头不是本题材的交付路径。

## 和「石榴的好奇实验室」的边界

| | 本题材插件 | 不搬过来的部分 |
| --- | --- | --- |
| 画面 | Remotion / SVG / 程序化图形 | IP 角色、多模态生成片、实拍棚 |
| 声音 | 主 Skill 的 TTS 选型与口播驱动时间轴 | 品牌配音棚、未在本仓库验证的供应商排名 |
| 结构 | 钩子 → 事实 → 为什么 → 对照/实验 → 小黑板 | 固定栏目包装、品牌片头片尾 |
| 验收 | 规格、一次一事抽帧、听感 | 石榴 G0–G12 自动门、ASR 对稿门禁、事实单源流水线 |

对照样片时可以看信息密度和中间是否加厚；不要把对方的门禁、品牌资产或生成管线写进本仓库。

## 信息结构（硬性）

面向约 3–8 岁口语科普。主题不限定：光、水、声音、植物都可以，但段落顺序固定。

1. **开场钩子**：一个能看见的现象 + 一句真问题。
2. **可记住事实**：只立一条孩子能复述的观察。
3. **为什么**：把因果画完整，不能只丢名词。
4. **小对照 / 小实验**：同一条事实换一个角度看，或给一个大人陪同的小动作。
5. **结尾小黑板**：只复述已经讲过的要点，可加一句行动；不得塞新知识。

中间三段必须「加厚」。不能钩子之后直接跳小黑板，也不能用三张标语代替机制。每 10 秒大约只让观众带走一个可记住的点；字卡过多或过快时先删句，不要加快全部动画。

彩虹样例（约 58 秒，v2）的落点：

| 段落 | 本镜让孩子带走什么 | 画面主事件 |
| --- | --- | --- |
| 钩子 | 雨后会出现彩虹，并产生「从哪来」的问题 | 雨停 → 太阳升起 → 彩虹画出 → 问号 |
| 事实 | 白光里藏着七色 | 一束白光逐条分成红橙黄绿青蓝紫 |
| 为什么 | 小水滴让光拐弯并分开颜色 | 进入折射 → 后壁反射 → 射出分色 → 约等于三棱镜 |
| 对照/实验 | 红在最外圈、紫在最里圈；喷雾可看见小彩虹 | 七色弧逐圈画；喷壶 +「大人陪同」 |
| 小黑板 | 复述三句已讲内容 | 错位 chalk 要点，不新增概念 |

技术短片仍可用主 Skill 的「冲突 → 机制 → 证据 → 限制」；儿童科普不要套成相同的产品五段式，也不要为了凑页数拆散语义。

## 口语、字卡与时间轴

- 句子短、能上口。先给看见的东西，再给原因。问句只在真的发问时上扬。
- 一次只出一张字卡，左右交替，带一条色边；不要居中堆成字墙。关键词可少量高亮，正文保持高对比。
- **口播驱动时间轴**：先按真实 TTS 时长生成 `timeline.json`（每句 `from` / `dur`），画面动作卡在对应句子开头。不能用字数等分冒充时间戳。样例用 `gen_audio.py` 写时间线，再让 `Sequence` 按场景和旁白切片。
- 草稿可用 Edge TTS；正式音色仍按 [TTS 选型](tts-selection.md) 和 [声音导演](voice-and-sound.md) 选择。样例的 `zh-CN-XiaoxiaoNeural` 只证明这条管线能跑，不是本题材的默认声音。
- 有旁白就不能把 Motion Lab 的无声示例当成正式片默认。BGM / SFX 让路给口播；动作点才给短促提示音。

## 动效禁忌（v1 翻车 → v2 纠正）

样例 v1 被评为「太 low」的具体原因，本题材当作默认禁令：

| 禁止 | 改成 |
| --- | --- |
| 居中大字墙、一句叠一句 | 单句字卡左右错位，一次一张 |
| 通篇线性淡入、全体同时出现 | 每句只触发一个动作 |
| 整段无意义 `scale(1 → 1.05)` | 场景之间最多短溶解，主体不靠呼吸缩放撑场 |
| 一次动太阳、彩虹、字卡、粒子 | 太阳升完再画弧，画完再弹问号 |
| 紫蓝渐变套娃、夜间科幻底 | 暖纸底 + 墨蓝字的绘本色板 |
| `transform: scale(...)` 字符串 | `translate` / `scale` 属性；inline `interpolate` + `Easing.bezier(0.16,1,0.3,1)` / `Easing.spring` |

一次只动一件事。辅助运动弱于主事件；装饰粒子可删就删。装 [remotion-dev/skills](https://github.com/remotion-dev/skills) 只为核对当前 Remotion 写法，不是本仓库的第二套 Skill。

## 科学与安全

- **示意也要画完整因果。** 水滴色散至少画出「进入折射 → 后壁反射 → 射出分色」。v1 只画「光一拐就散开」科学上偏弱，不能当正式片。
- **颜色用课本口径。** 儿童片写「红、橙、黄、绿、青、蓝、紫」。不要在同一条片子里混用「靛」和「青」，除非你在对照两种教材并解释差异。
- **实验必须写清大人陪同**，并写清观察条件（例如「晴天、背对太阳、喷水雾」）。不示范危险操作，不暗示孩子独自用火、锐器或化学品。
- 画面是扁平示意时，口播或字卡点明「这是示意图」，不要把简化光路说成实验室照片。
- 事实、推断、待验证项分开写。热门科普视频不能代替课本或一手资料。

## 实现要点

主路线仍是 Remotion 精确帧。儿童科普片通常先验证 2D 示意和口播对齐，不必上三维粒子。

- 场景做成独立组件，用 `Sequence` 按 `timeline.json` 切片并命名。
- 旁白用 `@remotion/media` 的 `<Audio>`；底乐与 SFX 跟最终时间轴，不要在组件里用墙上时钟。
- 字号、安全区、色板、缓动写入项目配置。修改文案后重跑时间线，不要只改画面时长。
- 依赖锁、资源来源、TTS 模型/音色写入工程。样例的 BGM / SFX 由 `gen_audio.py` 用正弦波与噪声合成，不引入不明版权素材。
- Remotion 运行库有自己的许可，见 [Remotion license](https://www.remotion.dev/license)。本仓库 MIT 不改变该依赖的权利条件。

## 验收（轻）

本题材不冒充石榴门禁，也不引入 G0–G12。做完主 Skill 的文件验收后，再抽查这几项：

1. **规格**：`ffprobe` 核对约定的宽高、帧率、时长；有声片听整段，不能只看响度数字。
2. **一次一事**：按句抽帧，确认该句只有一个主动作在进行；字卡是否左右错位、是否同时出现两张。
3. **中间加厚**：事实 / 为什么 / 对照三段都在，且为什么段的因果链完整。
4. **小黑板**：三项都能在前面找到出处，没有新名词。
5. **安全用语**：实验句含大人陪同；示意与真实有区分。

自动检查不能代替看画面和听口播。样例没有布局合同或成片/单帧对照；正式项目仍按 [渲染与验收](render-and-qa.md) 做。
