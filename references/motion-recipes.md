# 动效与材质方法

以下是实现路线，不是对任何参考片源码的认定。按叙事挑选，不要求每片使用全部效果。

## 三维视觉配方

| 效果 | 最小实现 | 质感关键 | 容易出错 |
| --- | --- | --- | --- |
| 白色褶皱球 | 在高细分球面上按法线施加平滑、低频的程序位移；旋转物体或改变形变参数 | 侧向主光、弱补光、柔和明暗、合适粗糙度；变形后更新法线或在 shader 中处理法线 | 位移太大呈尖刺；网格粗糙；只有环境光导致体积消失 |
| 球体分层展开 | 每层采用闭合圆盘/薄圆柱；球面切片半径 `r(y)=sqrt(max(0,R²-y²))`；展开时保持层级顺序 | 层间距、厚度、缓动和错峰；少量旋转；金色强调层 | 只切出无厚度平面；上下片半径不连续；接缝闪烁；参考有褶皱时理想球切片只能近似 |
| 起伏地形 | 细分平面顶点高度由空间坐标、固定种子噪声和时间计算 | 低角度镜头、斜侧光、多个尺度但有限的高度变化 | 每帧换随机噪声；高频波动像抖动；缺法线导致光照错误 |
| 轨道与卫星 | 局部平面轨迹 `x=a cos(theta), z=b sin(theta)`，再旋转轨道坐标系；物体与轨道线使用同一变换 | 速度差、遮挡、大小差、有限视差；主物体保持稳定 | 全部同速同相；轨道线与物体不一致；细线视频压缩后闪烁 |
| 金色不规则块 | 低频位移的闭合网格，标准/物理金属材质 | 反射环境、粗糙度和轮廓光；让高光随旋转变化 | 纯金色无环境反射，呈塑料；过曝变成白块 |
| 彩色虹彩物体 | 可尝试物理虹彩，或用法线/视角/噪声驱动的 shader 调色盘 | 将形变与颜色变化区分；保留连续色面和清晰轮廓 | 不要把参考彩色效果直接认定为物理虹彩；颜色切换频繁造成噪点 |
| 环带/陀螺 | 多个闭合环围绕同一中心，在不同局部轴上旋转 | 轴向差异、节奏差、遮挡层次 | 旋转太快失去结构；对象穿插无意遮挡文字 |

使用灯光/材质时先在一张静帧上调到成立。不要用 Bloom 掩盖缺少灯光层次的问题。金属材质需要反射来源；程序化环境也可以满足纯代码视觉要求。

## 排版与信息

- 将主文字、关键数字、主体物体和装饰标注分成层级。先让观众看见信息，再看见装饰。
- 严肃、精致的抽象宣传风格可用衬线标题、等宽标注和少量金色；中文字体必须实际验证字形、字重和断行。
- 技术说明片按概念组织版式，不强行沿用大英文标题和细小标注。
- 数字增长与空间事件同步：如层片展开时数字增长，到位后稳定停留。格式化按固定 locale 或明确规则，避免不同机器输出不同宽度。
- 数字使用等宽数字特性，预留最终位数与千分位空间。跳动数字不能承担必须逐字阅读的信息。
- 将细线和装饰小字视为可损失的信息层；手机主信息要单独检查。

## 运动与镜头

一个镜头通常包含三层运动：主事件（展开/聚合/变化）、辅助运动（旋转/轻微漂浮）、镜头运动（推进/观察角度变化）。让主事件最明显；不要三个层级同时争夺注意力。

为每个运动明确：起止时间、起止状态、缓动、停留时间、前后镜头关系。物体较重时减少弹跳，文字进入后留足阅读时间。

区分物体旋转与相机绕行。相机绕行会改变所有对象的视差、遮挡和背景关系，不能只给主物体加旋转来假装空间镜头。

## 转场

| 叙事目的 | 可选表达 |
| --- | --- |
| 同一个对象进入下一阶段 | 保持位置或轮廓，以形状、材质或结构变化连接 |
| 从全局切到细节 | 镜头推进/局部展开；留下必要的上下文 |
| 章节切换、强调一句话 | 黑白反转或有节制的硬切/擦除，按所选框架规则实现 |
| 技术状态变化 | 短暂切片、遮罩、色彩偏移；错误意义也通过标签/路径表达 |

故障效果使用固定种子与明确的时间窗。不要让正文长期出现 RGB 错位，也不要每次换镜都套同一故障模板。高频/大面积闪烁通常降低可读性，优先使用短促局部变化。

## 将机制映射成动画的示例

对于 Agent 循环：让“任务”成为持续可追踪的主体，让“计划”表现为分解后的步骤，让“调用”产生输入和结果，让“观察”显示结果与目标的差异，让“修正”真实改变下一次计划，让“验收”对应可见的证据。

不要让错误球变红之后就直接变绿。需要表现新尝试为何不同，以及通过验收所需的条件。这条原则适用于编译、部署、数据流水线等机制解释。
